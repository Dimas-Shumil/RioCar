# RioCar — мобильная админка

## Что изменено

- На экранах до 760 px вместо верхнего горизонтального меню отображается фиксированная нижняя навигация: **Обзор / Заявки / Клиенты / Авто / Ещё**.
- Кнопка «Ещё» открывает панель со всеми разделами, включая **Публикации**, а также ссылкой на публичный сайт и кнопкой выхода из аккаунта.
- Текущий раздел подсвечивается; страницы редактирования автомобилей и публикаций используют подсветку соответствующего родительского раздела.
- Меню закрывается кнопкой, нажатием на затемнение, клавишей Escape, при навигации или смене ширины на десктопную; фокус клавиатуры управляется в открытом меню.
- Учтены нижний системный отступ на iPhone (safe area), фиксированная панель не перекрывает основной контент.
- Доработаны мобильные отступы, заголовки, карточки показателей, списки, Web Push-блок.
- Десктопный сайдбар и работа существующих форм/API оставлены без изменений.

## Установка

1. Сделайте резервную копию проекта.
2. Если используете полный архив, замените проект, **не перезаписывая** рабочие `.env`, файл SQLite `prisma/dev.db`/`dev.db` и загруженные изображения. В архиве базы и `.env` нет.
3. Если используете патч — скопируйте содержимое поверх файлов проекта с сохранением структуры папок.
4. Перезапустите процесс Node, если на сервере включено кеширование HTML; для локальной разработки достаточно перезагрузить страницы.
5. На телефоне откройте админку и обновите страницу. CSS-путь содержит версию `?v=20261008-mobile` для сброса браузерного кеша.

**Никаких новых зависимостей, миграций Prisma или изменений `.env` для мобильного меню не требуется.**

## Проверка

```cmd
node --test tests/mobile-nav.test.cjs
npm run dev
```

Откройте на телефоне/через DevTools страницы `/admin/dashboard`, `/admin/requests`, `/admin/clients`, `/admin/cars`, `/admin/publications`, а также редактирование автомобиля и публикации. Проверьте навигацию, открытие «Ещё», формы редактирования, модальные окна и выход из аккаунта.
