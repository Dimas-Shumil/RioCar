# Web Push для RioCar

## Первичная настройка

1. Выполните `npm ci` (пакет web-push включён в package-lock.json).
2. Однажды создайте VAPID-ключи: `npx web-push generate-vapid-keys`.
3. Используя `push.env.example` как подсказку, добавьте в **уже существующий** `.env` три переменные `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT=mailto:your-email@example.com`. Не меняйте ранее настроенный SMTP/DB и не перегенерируйте VAPID при каждом деплое.
4. Выполните `npx prisma migrate deploy` и `npx prisma generate`. Не используйте `migrate reset` — удалятся существующие данные.
5. Перезапустите сервер через PM2, например `pm2 restart <имя-приложения> --update-env`. Сервер должен работать за HTTPS (кроме localhost для разработки).
6. Откройте `/admin/dashboard` под администратором. Нажмите **Включить**, разрешите уведомления, затем **Проверить**. На втором устройстве включайте отдельно.

## iPhone / iPad

В Safari откройте сайт, выполните **Поделиться → На экран «Домой»**, запустите RioCar **именно с иконки** и войдите в админку. Затем включите уведомления кнопкой в разделе «Обзор». В обычной вкладке Safari на iOS Web Push не поддерживается. Требуется iOS/iPadOS 16.4+.

## Проверка

После подписки выполните тестовую отправку из админки. Затем отправьте заявку через публичную форму. Должно прийти push с номером заявки, именем, автомобилем и телефоном; нажатие открывает карточку заявки. SMTP-письмо продолжает работать независимо.

## Безопасность и обслуживание

Подписки доступны только авторизованным администраторам. Изменение подписок и тест требуют CSRF и проверку Origin. Push endpoint и криптографические ключи подписок хранятся в SQLite, никогда не возвращаются публично. Статус 404/410 от push-провайдера автоматически удаляет недействительную подписку. Если сменить VAPID-ключи — потребуется повторно включить уведомления на каждом устройстве.

Важно: Chrome/Android и браузеры на компьютере могут доставлять уведомления при закрытой вкладке при условии, что устройство в сети и браузер/служба push разрешены ОС. Принудительное завершение браузера, энергосбережение и отключённые уведомления могут препятствовать доставке.

## Локальные проверки

После установки зависимостей запустите `npm test`: тесты покрывают формирование уведомления, рассылку на несколько устройств, удаление просроченных подписок и тестовую отправку выбранному администратору.
